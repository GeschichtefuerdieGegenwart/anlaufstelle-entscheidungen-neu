# Entscheidungen Leitfaden Anlaufstelle (Sitzung 05.10.2026)

Interaktive Seite, auf der die Projektgruppe die offenen Punkte D1–D18 des Leitfadens zur schulischen Anlaufstelle für Diskriminierungsschutz entscheidet. Die Ergebnisse lassen sich anschließend als PDF ausgeben.

- Eingaben werden nur im jeweiligen Browser gespeichert (localStorage) und nicht übertragen.
- „Ergebnisse und PDF“ → „Als PDF speichern“ öffnet den Druckdialog mit dem Protokoll.
- Über eine JSON-Sicherung lassen sich Eingaben auf ein anderes Gerät übertragen.
